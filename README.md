# Thalia Agent

The public project website for a planned open-source assistant for B2B proposal follow-up.

The agent itself has not been built. Email integration and message sending are not available. This repository currently contains the static website, not a working agent.

## Website

The site is plain HTML and CSS with locally hosted assets. It has no build step or runtime dependencies. To preview it locally, serve the repository root with any static file server.
